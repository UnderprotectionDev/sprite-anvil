# Use engine-neutral export with Godot as the first verified adapter

The Engine-Neutral Bundle is the canonical export contract, and engine-specific outputs are adapters derived from it. Each generated Export Bundle is immutable and pins its Context Revision, exact Unit and Composite Versions, QA evidence and waivers, schema version, and adapter version; “latest export” is only a pointer to one such bundle. A bundle may intentionally use historical Context Revisions or Canonical Designs when every dependency is explicit and its compatibility report contains no unresolved Revalidation Required item without a Quality Waiver. Godot is the first required Verified Engine Adapter; Unity becomes verified only after its golden-project contract passes and is not an initial completion dependency. A verified adapter publishes supported engine versions and passes maintained golden-project checks for frame rectangles, pivots, timing, events, texture settings, and applicable tile or UI behavior. This prevents either engine from becoming the Workbench's source of truth and makes “engine-ready” reproducible, while increasing manifest detail, storage use, and the ongoing compatibility-test burden.
