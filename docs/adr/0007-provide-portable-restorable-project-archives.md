# Provide portable restorable project archives

The completed product will export and restore a schema-versioned Project Archive containing Project Context revisions, asset relationships and all version files, reference roles, approval and QA history, export manifests, and optionally included working files, while excluding credentials and secrets. Restore creates an independent project by default, remaps its cloud identity, and preserves internal relationships; it never overwrites or automatically merges with an existing project. This makes the cloud-authoritative production memory portable and recoverable without putting live work at risk, at the cost of long-term schema migration, integrity verification, potentially large archives, and duplicate projects after restore.
