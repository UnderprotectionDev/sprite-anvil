# Require web and desktop product surfaces

Both the desktop application and the web application are mandatory product surfaces, backed by authoritative cloud state. The complete Core Production Lifecycle must be achievable on both surfaces, but the implementations need not be identical: desktop may add local folder watching and external-editor handoff when web provides a manual route to the same production outcome. Offline desktop use is limited to cached viewing and staging imported files or recoverable Working Drafts; approval, Context Revision activation, and verified export become authoritative only after synchronization. This supports browser accessibility and resilient local preparation together with operating-system affordances, while accepting cloud dependence, a synchronization queue, and the ongoing delivery and compatibility cost of two first-class surfaces.
