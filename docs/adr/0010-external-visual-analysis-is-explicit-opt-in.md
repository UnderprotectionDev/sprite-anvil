# External visual analysis is explicit opt-in

External Visual Analysis is disabled by default and requires separate permission for each project and analysis category. Before transmission, the product shows the files or data to be sent, the purpose, provider, and known retention conditions; deterministic checks and manual comparison remain available without permission. Because disclosure cannot be undone after transmission, this privacy boundary takes precedence over frictionless automated QA, at the cost of more consent interactions and provider-policy maintenance.
