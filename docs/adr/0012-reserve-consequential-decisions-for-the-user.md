# Reserve consequential decisions for the user

AI agents may author Context Proposals, Generation Packages, candidate imports, dependency suggestions, and QA reports, but only the user may activate Context Revisions or Required Sets, select Canonical Designs, record Review Events or Quality Waivers, and authorize permanent erasure. Export may run only after an explicit user request and successful gates. When a Context Agent is unavailable, structured controls may deterministically create common Context Proposals, but raw `context.md` editing does not become a fallback. This keeps agents productive without delegating artistic truth or irreversible decisions, at the cost of additional human gates and structured fallback controls.
