# Make reference transfer boundaries deterministic

Every Reference Role will declare allowed and forbidden feature transfers instead of relying on attachment order or model interpretation. An explicit prohibition overrides a general allowance, Canonical Design identity locks can be crossed only through an explicit Context Override, and unresolved conflicts at equal specificity block Generation Package creation. This makes the product's central promise—taking pose without accidentally taking identity, clothing, palette, or theme—auditable and repeatable, at the cost of more detailed reference annotation and pre-generation conflict handling.
