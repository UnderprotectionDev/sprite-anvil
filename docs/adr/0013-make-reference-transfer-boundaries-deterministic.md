# Make reference transfer boundaries deterministic

Every Reference Role declares allowed and forbidden feature transfers instead of relying on attachment order or model interpretation. Within one Asset Record, an allowance and prohibition for the same feature form an unresolved conflict; the reference board shows the involved rules, and Generation Package creation stops until the user edits a rule to remove the overlap. Once resolved, the package preserves each Reference Role's boundary. Canonical Design identity locks can be crossed only through an explicit Context Override. This makes the product's central promise—taking pose without accidentally taking identity, clothing, palette, or theme—auditable and repeatable, at the cost of requiring the user to resolve contradictory annotations before each affected attempt.
