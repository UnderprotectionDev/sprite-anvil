# Make reference transfer boundaries deterministic

Every Reference Role declares allowed and forbidden feature transfers instead of relying on attachment order or model interpretation. If one role explicitly forbids a feature another role allows, the prohibition takes precedence and the feature remains forbidden in the Generation Package; this overlap does not block package creation. Canonical Design identity locks can be crossed only through an explicit Context Override. This makes the product's central promise—taking pose without accidentally taking identity, clothing, palette, or theme—auditable and repeatable, at the cost of more detailed reference annotation.
