# 02 — Ayrışmayı Çözerek Yenileme

**What to build:** Kullanıcı **Ayrışmayı Çözerek Yenileme** adımını baştan sona tamamlar: Değişmemiş, güncellenecek, bayat, eksik ve ayrışmış yollar ayrı gösterilir; kullanıcı kararından sonra izinli yollar yeni paketle yenilenir. Yenilemeden önce yalnız sahip olunan yollar eski kilitle karşılaştırılır.
