# 02 — Sonucu ve Başarısızlık Kaynağını Kesinleştirme

**What to build:** Kullanıcı **Sonucu ve Başarısızlık Kaynağını Kesinleştirme** adımını baştan sona tamamlar: Bağdaştırıcı taslak hazırlayabilir; sonucu ve etkilenen yeniden doğrulama kapsamını yalnız kullanıcı kesinleştirir.
