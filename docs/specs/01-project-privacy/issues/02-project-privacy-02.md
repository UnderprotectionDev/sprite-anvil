# 02 — Teslim çıktılarında sırları dışlama

**What to build:** Kullanıcı **Teslim çıktılarında sırları dışlama** adımını baştan sona tamamlar: Arşiv, Dışa Aktarım Paketi, telemetri ve kaynak geçmişi şifreleme anahtarı, erişim belirteci veya sunucu yürütme sırrı taşımaz. Yönetilen bulut verisi aktarımda ve depoda korunur.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Arşiv, Dışa Aktarım Paketi, telemetri ve kaynak geçmişi şifreleme anahtarı, erişim belirteci veya sunucu yürütme sırrı taşımaz. Yönetilen bulut verisi aktarımda ve depoda korunur.
- [ ] Yetkisiz proje erişimi reddedilir; korunan içerik ve sırlar istemci ile teslim çıktılarında bulunmaz.
- [ ] Kapsam sınırları korunur: Dış araca amaç ve kapsamla erişim verme, ayrı kullanıcı izin akışıdır; erişim kararı sanatsal onay yetkisi oluşturmaz.
